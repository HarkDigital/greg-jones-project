# Greg Jones Project — site concept

A concept site for Greg Jones Project (gregjonesproject.com), built on the
Hark concept engine: a small warm room after dark with one acoustic guitar at
the heart of it — Greg's Martin OMCPA4 (000 cutaway, Sitka spruce, sapele,
black binding, tortoise pickguard, DADGBD) with strings that really ring. The
chapters are joined by a soundhole cut (the frame shrinks into the soundhole
of the guitar; the next scene opens out of it). All copy is verbatim from
gregjonesproject.com, its EPK, Bandcamp and Apple Music.

**Live (noindex):** https://harkdigital.github.io/greg-jones-project/

```bash
npm install
npm run dev
npm run build
```

Kit (`src/kit/`): `guitar.ts` (the acoustic), `strings.ts` (vibrating
strings + `Ring`), `stage.ts` (floor, cables, pedals), `materials.ts`,
`pace.ts` (StoryClock). Look lab: `?lab&view=stand|top|macro|head|hole`.
